## Purpose
Configuration for deploying static site to Cloudflare Pages via Wrangler CLI.

name = "golden-ratio-fractal-engine"
compatibility_date = "2025-01-01"
pages_build_output_dir = "dist"
```

## Configuration

### Project Name

name = "golden-ratio-fractal-engine"
```
- **Cloudflare project identifier**
- **Used in**: Deployment URLs, dashboard

### Compatibility Date
```toml
compatibility_date = "2025-01-01"
```
- **Cloudflare Workers/Pages runtime version**
- **Format**: YYYY-MM-DD

### Build Output
```toml
pages_build_output_dir = "dist"
```
- **Static files directory**: `dist/`
- **Generated by**: `vite build`
- **Contains**: HTML, JS, CSS, assets

## Deployment Commands
```bash
# Build the project
npm run build  # or bun run build

# Deploy to Cloudflare Pages
wrangler pages deploy dist

# Or via npm script
npm run deploy:cf
```

## Critical Notes
1. **Static site**: No server-side rendering, pure SPA
2. **dist/ directory**: Must run `vite build` before deploy
3. **No functions**: No Cloudflare Workers (serverless functions)
4. **No KV/R2**: No key-value or object storage
5. **Minimal config**: Only essential settings
6. **Auto-detection**: Cloudflare auto-detects framework (Vite)

## Deployment URL
After deployment, site available at:
```
https://golden-ratio-fractal-engine.pages.dev
```
