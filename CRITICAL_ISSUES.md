# Критические проблемы и решения

## ПРОБЛЕМА 1: Черные фракталы (не видно)

### Корневая причина:
Некоторые функции `map*` в шейдерах возвращают неправильные значения SDF.

### Что уже исправлено:
✅ Добавлены 20 недостающих маппингов в `fractalMappers.ts`
✅ Увеличена дистанция рендеринга (8x)
✅ Улучшена детализация (5x)

### Что нужно проверить:
⚠️ Функции `map*` для новых типов (30-85) могут возвращать неправильные значения
⚠️ Нужно добавить логирование для определения каких фракталов не видно

## ПРОБЛЕМА 2: Меньше 10 фракталов вместо сотен

### Корневая причина:
Система рекомендаций использует Thompson sampling с anti-repetition penalty.

### Как работает:
1. `ALL_FRACTAL_TYPES` = 86 типов ✅
2. Thompson sampling выбирает типы на основе affinity
3. `recentTypes` penalty = 0.05 для недавно показанных
4. История ограничена 100 экземплярами

### Почему мало фракталов:
- Система НЕ показывает все 86 типов последовательно
- Thompson sampling предпочитает типы с высоким affinity
- Anti-repetition может быть слишком агрессивным

### Решение:
1. Уменьшить `recentPenalty` с 0.05 до 0.2
2. Увеличить `RECENT_WINDOW` с 20 до 50
3. Добавить "exploration mode" для показа всех типов

## ПРОБЛЕМА 3: Мало гибридов (не тысячи)

### Корневая причина:
Гибриды создаются только из `COMPATIBLE_HYBRIDS` матрицы.

### Матрица совместимости:
- 89 типов в `COMPATIBLE_HYBRIDS` ✅
- Каждый тип имеет 4-5 партнеров
- 8 composite operations

### Почему мало гибридов:
- Система выбирает только из совместимых партнеров
- Не все комбинации генерируются
- Нет "random hybrid" режима

### Решение:
1. Добавить режим "random hybrid" - любая комбинация
2. Увеличить количество партнеров в матрице
3. Добавить "hybrid exploration" режим
